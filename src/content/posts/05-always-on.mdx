## 무엇이 달라지나

| | 4단계 | 5단계 |
| --- | --- | --- |
| 서버를 띄우는 쪽 | 내가 터미널에서 | macOS(launchd)가 알아서 |
| 터미널 창을 닫으면 | 꺼짐 | 그대로 |
| 서버가 죽으면 | 그대로 꺼져 있음 | 다시 뜸 |
| 서버를 다시 켜면 | 꺼져 있음 | 로그인 없이 뜸 |
| GPU 몫 22GB(2단계) | 다시 켜면 사라짐 | 켜질 때마다 다시 적용 |
| 질문 기록 | 터미널 화면에만 | 파일에 쌓임 |

표의 GPU 몫은 macOS가 GPU에 쓰라고 내주는 메모리입니다.

macOS에서 「켜지면 알아서 도는 프로그램」은 launchd가 맡습니다. 정해진 폴더에 설정 파일인 plist를 두면, launchd가 그 내용대로 프로그램을 띄우고 지켜봅니다. 폴더는 두 가지입니다.

| 폴더 | 이름 | 언제 뜨나 |
| --- | --- | --- |
| `~/Library/LaunchAgents` | 에이전트 | 그 사용자가 로그인한 뒤 |
| `/Library/LaunchDaemons` | 데몬 | 켜지자마자, 로그인과 상관없이 |

목표가 「로그인 없이」라서 데몬으로 했습니다. 데몬이라도 실제 프로그램은 제 사용자 이름으로 돌릴 수 있습니다.

## 켜기 전에 확인한 것

<Code title="터미널, 서버">

```sh
$ fdesetup status
FileVault is Off.
$ pmset -g
 sleep                0
 disksleep            0
 autorestart          1
```

</Code>

- **FileVault가 꺼져 있어야 한다.** FileVault는 디스크를 암호로 잠그는 기능이다. 켜져 있으면 다시 켤 때 디스크가 잠긴 채 로그인 화면에서 멈춘다. 누군가 암호를 넣기 전까지는 데몬도 뜨지 않는다.
- 잠자기는 0단계에서 이미 꺼 두었다. `autorestart 1`은 정전 뒤 전기가 들어오면 저절로 켜진다는 뜻이다.

## launchd에 맡기기

Claude가 서버의 `~/llm-service` 폴더에 파일 다섯 개를 만들었습니다.

| 파일 | 하는 일 |
| --- | --- |
| `com.cyborg.mlx-server.plist` | MLX 서버를 띄우고 지켜본다 |
| `com.cyborg.gpu-limit.plist` | 켜질 때마다 GPU 몫을 22GB로 올린다 |
| `start-mlx.sh` | 22GB가 적용됐는지 확인한 뒤 서버를 시작한다 |
| `install.sh` / `uninstall.sh` | 설치 / 되돌리기 |

<Code title="com.cyborg.mlx-server.plist, 중요한 줄만">

```xml
<key>UserName</key><string>(내 사용자 이름)</string>
<key>ProgramArguments</key>
<array><string>~/llm-service/start-mlx.sh</string></array>
<key>RunAtLoad</key><true/>
<key>KeepAlive</key><true/>
<key>ThrottleInterval</key><integer>30</integer>
<key>ProcessType</key><string>Interactive</string>
<key>StandardOutPath</key><string>~/llm-logs/mlx-server.log</string>
```

</Code>

| 설정 | 뜻 |
| --- | --- |
| `UserName` | 관리자가 아니라 내 사용자 이름으로 돌린다 |
| `RunAtLoad` | 켜지자마자 띄운다 |
| `KeepAlive` | 꺼지면 다시 띄운다 |
| `ThrottleInterval` | 너무 자주 죽으면 30초를 기다렸다 다시 띄운다 |
| `ProcessType` | 뒷전 작업으로 낮춰 돌리지 말고 제 속도로 돌린다 |
| `StandardOutPath` | 서버가 찍는 줄을 이 파일에 쌓는다 |

<Code title="start-mlx.sh">

```sh
for i in $(seq 1 60); do
  [ "$(sysctl -n iogpu.wired_limit_mb)" = "22528" ] && break
  sleep 1
done
echo "$(date "+%Y-%m-%d %H:%M:%S") start: GPU limit $(sysctl -n iogpu.wired_limit_mb) MB"
exec mlx_lm.server --model ~/models/mlx/Qwen3.8-27B-4bit --host 0.0.0.0 --port 8080 \
  --chat-template-args '{"enable_thinking":false}'
```

</Code>

GPU 몫을 올리는 일과 서버를 띄우는 일은 따로 돌아서 어느 쪽이 먼저 뜰지 알 수 없습니다. MLX는 시작할 때 GPU 몫을 한 번 읽고, 그 뒤로는 계속 그 값을 씁니다. 그래서 22GB가 적용될 때까지 최대 60초 기다린 뒤 서버를 시작하게 했습니다.

<Note title="열어 둔 범위">
4단계처럼 사무실 망 전체에서 질문을 받게 두었습니다. 아직 열쇠가 없어서 같은 망에 있으면 누구나 쓸 수 있습니다. 그런 상태로 늘 켜져 있게 됩니다. 서버 안에서만 받게 하는 쪽을 권했지만, 쓰기 편한 쪽을 골랐습니다. 열쇠는 7단계에서 붙입니다.
</Note>

## 설치

`/Library/LaunchDaemons`는 관리자만 쓸 수 있는 폴더입니다. 그래서 설치는 제가 암호를 넣고 했습니다.

<Code title="터미널, 서버">

```sh
$ sudo ~/llm-service/install.sh
installed com.cyborg.gpu-limit
installed com.cyborg.mlx-server
$ tail -2 ~/llm-logs/mlx-server.log
2026-11-13 18:27:37 start: GPU limit 22528 MB
INFO - Starting httpd at 0.0.0.0 on port 8080...
```

</Code>

## 세 가지 시험

**하나, 혼자 뜬 서버가 GPU로 답하나.** launchd가 띄운 프로그램은 화면 없이 돕니다. 그래서 GPU를 못 쓸까 걱정했습니다. 그런데 「한 문장으로 자기소개해 줘」에 27토큰을 5초 만에 답했습니다. 토큰은 모델이 글을 끊어 쓰는 단위입니다.

**둘, 죽이면 다시 뜨나.** 서버 프로그램을 일부러 끝냈습니다.

<Code title="터미널, 서버">

```sh
$ kill (서버 번호)
killing 69128 at 18:28:33
restarted as 70485 at 18:28:36
```

</Code>

3초 만에 새 번호로 다시 떴습니다. 18:28:48에는 다시 질문을 받았습니다.

**셋, 껐다 켜도 로그인 없이 뜨나.** `sudo reboot`로 다시 켠 뒤, 서버 앞에서 로그인하지 않고 두었습니다.

<Code title="터미널, 서버">

```sh
$ uptime
18:31  up 2 mins, 0 users
$ sysctl kern.boottime
kern.boottime: { sec = 1794562185, usec = 289672 } Fri Nov 13 18:29:45 2026
$ grep -E "start|Starting" ~/llm-logs/mlx-server.log | tail -2
2026-11-13 18:29:51 start: GPU limit 22528 MB
INFO - Starting httpd at 0.0.0.0 on port 8080...
```

</Code>

18:29:45에 켜졌고, **6초 뒤** 서버가 시작했습니다. 로그인한 사용자는 0명이었습니다. 「방금 다시 켜졌어. 한 문장으로 인사해 줘」에는 「다시 만나서 반갑습니다, 오늘도 좋은 하루 보내세요!」라고 답했습니다.

## 되돌리는 법

<Code title="터미널, 서버">

```sh
$ sudo ~/llm-service/uninstall.sh
removed com.cyborg.mlx-server
removed com.cyborg.gpu-limit
```

</Code>

기록 파일에는 질문 하나에 몇 줄씩 쌓입니다. 하루 수백 건이어도 1MB 남짓이라 아직은 자르지 않았습니다. 많이 쓰게 되면 일정 크기마다 잘라 두게 하겠습니다.

## 배운 것

- macOS에서 켜지자마자 도는 프로그램은 launchd의 데몬으로 만든다. 로그인 뒤에 도는 에이전트와 폴더가 다르다.
- 「로그인 없이」의 조건은 FileVault다. 켜져 있으면 디스크가 잠겨서 아무것도 뜨지 않는다.
- `KeepAlive` 한 줄이면 죽은 서버가 다시 뜬다.
- 켜질 때 함께 도는 일은 순서가 정해져 있지 않다. GPU 몫처럼 먼저 필요한 값이 있으면 기다렸다 시작하게 한다.
- 늘 켜 두면 늘 열려 있다. 열쇠가 필요해졌다.
