## 1. 암호 없이 들어가는 열쇠

암호로 들어가면 그때마다 사람이 있어야 합니다. 그래서 열쇠 한 쌍을 만듭니다. 자물쇠는 서버에 걸어 두고, 열쇠는 내 컴퓨터에만 둡니다. 자물쇠를 공개 키, 열쇠를 개인 키라고 부릅니다. 이렇게 해 두면 **Claude가 혼자서도 서버에 들어가 일할 수 있습니다**.

<Note title="주의">
터미널은 명령을 글자로 쳐서 컴퓨터를 다루는 창입니다. 여기서 암호를 칠 때는 영문 입력 상태인지 먼저 확인하세요. 한글 상태로 치면 다른 글자가 들어가 암호가 맞지 않습니다. 암호를 치는 동안 화면에 아무것도 나타나지 않아도 정상입니다.
</Note>

<Code title="터미널, 내 컴퓨터">

```sh
# 열쇠 한 쌍 만들기
$ ssh-keygen -t ed25519
# 서버에 등록, 암호는 이때 한 번
$ ssh-copy-id mini2
# 이제 암호 없이 들어간다
$ ssh mini2
```

</Code>

`mini2`는 서버 주소 대신 부르는 이름입니다. 설정 파일에 한 번 적어 두면 주소를 외우지 않아도 됩니다.

<Code title="~/.ssh/config" file>

```text
Host mini2
  HostName 192.168.x.x
  User me
  IdentityFile ~/.ssh/id_ed25519
```

</Code>

## 2. 잠들지 않게

컴퓨터는 아무도 만지지 않으면 잠듭니다. 사람이 쓰는 컴퓨터라면 맞는 동작입니다. 하지만 질문이 언제 올지 모르는 LLM 서버에는 맞지 않습니다. 이 명령은 관리자 암호가 필요해서 제가 직접 쳤습니다.

<Code title="터미널, 서버">

```sh
$ sudo pmset -a sleep 0 disksleep 0 autorestart 1
```

</Code>

## 3. 설치 도구

LLM 엔진은 모델을 돌리는 프로그램입니다. 이 엔진을 소스 코드에서 직접 빌드하려면 Homebrew가 필요합니다. Homebrew는 macOS용 설치 도구입니다. 설치하는 동안 애플 개발 도구가 먼저 깔렸고, 1분 뒤 Homebrew 설치가 끝났습니다.

<Code title="터미널, 서버">

```sh
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

</Code>

마지막으로 brew를 어디서나 찾도록 경로를 등록했습니다. SSH로 원격에서 명령 한 줄만 보낼 때도 찾아야 합니다. 그래서 두 파일에 같은 줄을 넣었습니다.

<Code title="~/.zprofile, ~/.zshenv" file>

```sh
eval "$(/opt/homebrew/bin/brew shellenv)"
```

</Code>
