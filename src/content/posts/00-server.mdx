## 1. 암호 없이 들어가는 열쇠

매번 비밀번호를 치는 대신 열쇠 한 쌍을 만듭니다. 자물쇠(공개 키)는 서버에 걸어 두고, 열쇠(개인 키)는 내 컴퓨터에만 둡니다. 이렇게 해 두면 **Claude가 혼자서도 서버에 들어가 일할 수 있습니다**.

<Note title="주의">
터미널에서 암호를 칠 때는 영문 입력 상태인지 먼저 확인하세요. 한글 상태로 치면 다른 글자가 들어가 암호가 맞지 않습니다. 칠 때 화면에 아무것도 보이지 않는 것은 정상입니다.
</Note>

<Code title="터미널, 내 컴퓨터">

```sh
# 열쇠 한 쌍 만들기
$ ssh-keygen -t ed25519
# 서버에 등록, 암호는 이때 한 번
$ ssh-copy-id mini2
# 이제 암호 없이 들어간다
$ ssh mini2
```

</Code>

`mini2`는 주소 대신 부르는 이름입니다. 설정 파일에 한 번 적어 두면 주소를 외울 필요가 없습니다.

<Code title="~/.ssh/config" file>

```text
Host mini2
  HostName 192.168.x.x
  User me
  IdentityFile ~/.ssh/id_ed25519
```

</Code>

## 2. 잠들지 않게

컴퓨터는 아무도 만지지 않으면 잠듭니다. 사람이 쓰는 컴퓨터라면 맞는 동작이지만, 언제 질문이 올지 모르는 LLM 서버에는 맞지 않습니다. 관리자 암호가 필요한 명령이라 이 줄은 제가 직접 쳤습니다.

<Code title="터미널, 서버">

```sh
$ sudo pmset -a sleep 0 disksleep 0 autorestart 1
```

</Code>

## 3. 설치 도구

LLM 엔진을 직접 빌드하려면 macOS용 설치 도구인 Homebrew가 필요합니다. 설치하는 동안 애플 개발 도구가 먼저 깔리고, 1분 뒤 Homebrew가 끝났습니다.

<Code title="터미널, 서버">

```sh
$ /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
```

</Code>

마지막으로 brew를 어디서나 찾도록 경로를 등록했습니다. SSH로 명령 한 줄만 보낼 때도 찾을 수 있게 두 파일에 같은 줄을 넣었습니다.

<Code title="~/.zprofile, ~/.zshenv" file>

```sh
eval "$(/opt/homebrew/bin/brew shellenv)"
```

</Code>

## 배운 것

- LLM 서버는 성능보다 먼저, 늘 켜져 있고 원격으로 들어갈 수 있어야 한다.
- 열쇠 로그인을 해 두면 Claude가 혼자 서버에 들어가 일할 수 있다.
- 관리자 암호가 필요한 명령은 사람이 직접 쳐야 한다.
