개인정보와 방문 통계

이 블로그는 회원 가입, 댓글, 입력 양식이 없습니다. 이름이나 이메일 같은 정보를 직접 받지 않습니다.

방문 통계를 위해 Google Analytics를 씁니다. 페이지를 열면 브라우저에 쿠키가 저장됩니다. 본 페이지 주소, 들어온 경로, 기기와 브라우저 종류, 대략적인 지역 같은 정보가 Google로 갑니다. 이 정보로 글별 방문 수와 바닥글의 「오늘·전체」 방문자 수를 냅니다.

정보 처리 방식은 Google이 파트너 사이트의 정보를 사용하는 방법에서 확인할 수 있습니다.

브라우저 설정에서 쿠키를 막거나, Google 애널리틱스 차단 브라우저 부가기능 또는 추적 차단 확장 프로그램을 쓰면 방문 통계 수집을 막을 수 있습니다. 막아도 글은 그대로 읽을 수 있습니다.

이 블로그는 GitHub Pages로 서비스됩니다. GitHub는 보안을 위해 방문자의 IP 주소를 기록하고 보관합니다. 자세한 내용은 GitHub Pages의 정보 수집 안내에서 확인할 수 있습니다. 블로그 운영자는 이 기록을 받지 않습니다.

문의는 GitHub로 보내 주시면 됩니다.
