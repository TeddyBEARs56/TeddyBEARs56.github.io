LLM을 올릴 서버 준비하기

LLM 서버는 질문이 언제 올지 모릅니다. 그래서 모델보다 먼저, 늘 켜져 있고 원격으로 들어갈 수 있는 컴퓨터가 필요합니다. 이번 단계에서는 암호 대신 SSH 키로 들어가게 하고, 잠자기를 끄고, 설치 도구를 깝니다.

이번에 할 일

  1. SSH 키를 등록한다. 암호 없이 들어가야 Claude가 혼자 일할 수 있다.
  2. 잠자기를 끈다. 질문이 언제 올지 모른다.
  3. 설치 도구를 깐다. 엔진을 직접 빌드하려면 Homebrew가 필요하다.
  4. 설정을 점검한다. 뒤 단계에서 손볼 곳을 미리 적어 둔다.

설치 환경

막 초기화한 Apple M4 컴퓨터입니다. 앞으로 모델을 고를 때 가장 중요한 숫자는 메모리 24GB입니다. 모델은 이 안에 들어가야 돌아갑니다.

항목 값
칩 Apple M4, 성능 코어 4개와 효율 코어 6개
메모리 24 GB, CPU와 GPU가 함께 쓰는 통합 메모리
운영체제 macOS 27.0.1

1. 암호 없이 들어가는 SSH 키

암호로 들어가면 그때마다 사람이 있어야 합니다. 그래서 SSH 키를 씁니다. SSH 키는 암호 대신 접속하는 사람을 확인하는 데 쓰는 파일 두 개, 공개 키와 개인 키입니다. 공개 키는 서버에 등록해 두고, 개인 키는 내 컴퓨터에만 두고 남에게 주지 않습니다. 서버는 접속하는 쪽이 등록된 공개 키와 짝이 맞는 개인 키를 가졌는지 확인하고 들여보냅니다. 이렇게 해 두면 Claude가 혼자서도 서버에 들어가 일할 수 있습니다.

주의

터미널은 명령을 글자로 쳐서 컴퓨터를 다루는 창입니다. 여기서 암호를 칠 때는 영문 입력 상태인지 먼저 확인하세요. 한글 상태로 치면 다른 글자가 들어가 암호가 맞지 않습니다. 암호를 치는 동안 화면에 아무것도 나타나지 않아도 정상입니다.

mini2는 서버 주소 대신 부르는 이름입니다. 설정 파일에 한 번 적어 두면 주소를 외우지 않아도 됩니다.

2. 잠들지 않게

컴퓨터는 아무도 만지지 않으면 잠듭니다. 사람이 쓰는 컴퓨터라면 맞는 동작입니다. 하지만 질문이 언제 올지 모르는 LLM 서버에는 맞지 않습니다. 이 명령은 관리자 암호가 필요합니다.

3. 설치 도구

LLM 엔진은 모델을 돌리는 프로그램입니다. 이 엔진을 소스 코드에서 직접 빌드하려면 Homebrew가 필요합니다. Homebrew는 macOS용 설치 도구입니다. 설치하는 동안 애플 개발 도구가 먼저 깔렸고, 1분 뒤 Homebrew 설치가 끝났습니다.

마지막으로 brew를 어디서나 찾도록 경로를 등록했습니다. SSH로 원격에서 명령 한 줄만 보낼 때도 찾아야 합니다. 그래서 두 파일에 같은 줄을 넣었습니다.

배운 것

  • LLM 서버는 성능보다 먼저, 늘 켜져 있고 원격으로 들어갈 수 있어야 한다.
  • SSH 키로 로그인하게 해 두면 Claude가 혼자 서버에 들어가 일할 수 있다.
  • 관리자 암호가 필요한 명령은 사람이 직접 쳐야 한다.
