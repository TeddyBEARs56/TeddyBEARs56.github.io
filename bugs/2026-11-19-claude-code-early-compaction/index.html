Claude Code에 기억할 글 32,768토큰을 알려 주자 1만 1천 토큰마다 요약하다 멈췄다

알려 준 길이의 3분의 1쯤에서 요약이 시작됐습니다. 요약도 모델이 쓰는 글이라 한 번에 8~11분씩 걸렸고, 세 번째 요약 뒤에 멈췄습니다.

상태
우회
대상
Claude Code 2.1.326의 자동 요약
환경
Claude Code 2.1.326(macOS 27.0.1), LiteLLM 1.106.6 게이트웨이 뒤의 로컬 모델 서버(mlx-lm, llama.cpp)
올린 날
2026-11-19
읽는 시간
약 2분

증상

Mac mini에서 Claude Code를 로컬 모델로 돌렸습니다. Claude Code는 대화가 모델이 담을 수 있는 길이에 가까워지면 지난 대화를 요약해서 줄입니다. 처음 보는 모델 이름이면 그 길이를 100만 토큰으로 여기므로, 환경 변수로 직접 알려 줬습니다.

그러자 Qwen3.8 27B의 고치기 과제 한 번에서, 대화가 1만 1천 토큰대에 이를 때마다 요약했습니다.

요약 요약 전 대화 걸린 시간
첫 번째 11,848토큰 11분
두 번째 11,629토큰 8분
세 번째 11,498토큰 8분

요약도 모델이 쓰는 글이라 dense 모델에게는 한 번에 8~11분이 걸렸습니다. 세 번째 요약 뒤에 Claude Code는 이 오류를 내고 멈췄습니다. 고친 파일은 맞았지만 42분이 걸렸습니다.

재현 순서

  1. Claude Code 2.1.326에 위 두 환경 변수를 주고, 게이트웨이를 거쳐 로컬 모델로 돌린다.
  2. 파일을 여러 번 읽어야 하는 일을 맡긴다.
  3. 대화가 1만 1천 토큰대에 이르면 요약이 시작된다.

원인

확인한 것

  • 요약은 알려 준 길이보다 훨씬 앞에서 시작됐다. 32,768과 8,192에서는 11,498~11,848토큰, 49,152와 4,096에서는 3만 1천~3만 5천 토큰에서 요약했다.
  • 요약하고 세 번 주고받기 안에 다시 한도까지 차는 일이 세 번 연달아 일어나자, Claude Code가 스스로 멈췄다. 오류 문구가 그렇게 말한다.

추정한 것

  • 두 설정 모두 「알려 준 길이에서 답 몫과 1만 3천 토큰쯤을 뺀 곳」에서 요약했다. 32,768에서 8,192와 13,000을 빼면 11,576이고, 49,152에서 4,096과 13,000을 빼면 32,056이다. Claude Code가 답 몫 말고도 그만큼을 비워 두는 것으로 보인다. 이 값을 문서나 소스에서 확인하지는 못했다.

해결

기억할 글을 49,152로 늘리고, 답 몫을 4,096으로 줄였습니다. 서버도 같은 길이를 담아야 해서, 노트북의 llama.cpp는 -c 49152 -np 1로 띄웠습니다.

그 뒤로는 대화가 3만 1천~3만 5천 토큰에 이르러야 요약했습니다. 「로컬 LLM 처음부터」 11단계의 시험 가운데 아홉 번에서 합쳐 12번 요약했고, 한 번에 1~6분이 걸렸습니다. 요약 자체를 없앤 것은 아니라서 상태는 「우회」로 둡니다. 자세한 과정은 로컬 LLM 처음부터 12단계에 적었습니다.
