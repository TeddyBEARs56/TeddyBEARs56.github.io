Claude Code에 기억할 길이를 32K로 알려 주면 절반쯤에서 대화를 요약하고, 되풀이되면 답 없이 끝난다

알려 준 길이보다 1만 7천 토큰쯤 먼저 요약이 시작됩니다. 23KB 로그 하나로 문턱을 넘었고, 요약이 세 번 이어지자 Claude Code가 고친 결과를 두고도 오류로 끝냈습니다.

증상

Claude Code를 Mac mini의 Ollama에 바로 붙여, 실패한 배포를 고치게 했습니다. Ollama와 Claude Code 양쪽에 기억할 길이를 32,768토큰으로 정했습니다. 모델 두 개로 24번 돌렸는데, 24번 모두 Claude Code가 대화를 1~3번 자동으로 요약했습니다. 같은 일을 클라우드 모델로 돌린 62번에서는 한 번도 요약하지 않았습니다.

실행 기록에 남은 요약 직전 길이는 15,586~26,016토큰이었습니다. 알려 준 길이의 절반쯤에서 요약이 시작된 셈입니다. 요약 한 번에 Qwen3.6은 1~3분, Qwen3.8은 4~11분이 걸렸고, 요약에 쓴 시간이 전체의 45~48%였습니다.

Qwen3.6의 두 번은 파일을 제대로 고쳐 빌드가 통과한 뒤, 마지막 답 대신 이 문구로 끝났습니다.

이때 JSON 결과는 "subtype": "success"와 "is_error": true가 함께 나왔고, 종료 코드는 1이었습니다. 표준 오류에는 [claude-code:unrecognized_model]이 남았습니다.

재현 순서

  1. Ollama를 OLLAMA_CONTEXT_LENGTH=32768로 띄우고 로컬 모델을 받는다.
  2. ollama launch claude가 넣는 설정대로 Claude Code를 Ollama에 붙여 비대화형으로 실행한다.
  1. 작업 폴더에 23KB쯤의 빌드 로그를 두고, 읽고 고치게 한다. 첫 요청이 7,800토큰쯤이고, 로그를 통째로 읽으면 2만 1천 토큰쯤이 된다.
  2. 실행 기록(~/.claude/projects/…/<세션 ID>.jsonl)에서 compact_boundary 줄의 compactMetadata.preTokens를 보면 요약 직전 길이가 나온다.

원인

확인한 것

  • 요약은 알려 준 길이보다 1만 7천 토큰쯤 먼저 시작한다. 32,768로 알려 준 24번에서 요약 직전 길이가 가장 작았던 것은 15,586토큰이었다. 49,152로 알려 준 다른 시험에서는 3만 2천 토큰 안팎에서 요약했다. 두 경우 모두 1만 7천쯤을 남겼으니, 비율이 아니라 일정한 몫을 남기는 것으로 보인다.
  • 문턱이 낮아 큰 도구 결과 하나로 넘는다. 첫 요청 7,800토큰에 로그 1만 2천 토큰이 더해지면 문턱을 넘고, Qwen3.6은 12번 가운데 11번이 로그를 읽은 바로 다음 요청에서 요약했다.
  • 요약 뒤에도 금방 다시 차는 일이 세 번 이어지면, Claude Code가 일을 마쳤든 아니든 실행을 오류로 끝낸다. 위 문구가 그 조건(3턴 안에 다시 참, 세 번 연속)을 그대로 말한다.
  • 문서로는 문턱을 올릴 수 없다. 환경 변수 문서에서 CLAUDE_AUTOCOMPACT_PCT_OVERRIDE는 「the variable can’t raise the threshold」, CLAUDE_CODE_AUTO_COMPACT_WINDOW는 「a token count of 100000 or more」만 받는다고 적혀 있다.

추정한 것

  • 남기는 1만 7천은 한 번에 쓰는 답 4,096토큰에 1만 3천쯤의 여유를 더한 값으로 보인다. 32,768 − 4,096 − 13,000 = 15,672로 관찰과 맞지만, 문서에서 확인하지는 못했다.
  • 클라우드 모델은 기억할 길이가 훨씬 길어서 같은 몫을 남겨도 문턱에 닿지 않는다. 로컬 모델처럼 길이를 짧게 줄 때만 드러난다.

해결

아직 고치지 못했습니다. 지금까지 한 것과 남은 후보는 이렇습니다.

  • 성공 여부를 결과물로 판정했다. 종료 코드나 is_error로 판정했다면, 고치고 끝난 두 번도 실패로 셌을 것입니다. 이번 시험은 빌드 통과로 판정했습니다.
  • 로그를 통째로 읽히지 않는 방법이 있다. 로그를 건네지 않은 조건에서 클라우드 모델은 빌드를 직접 돌려 끝 40줄만 봤고, 출력이 0.8~1.8KB였습니다. 로컬 모델에게 이렇게 시켜 보지는 않았습니다.
  • 시험하지 않은 설정
    • DISABLE_AUTO_COMPACT=1은 자동 요약을 끕니다. 대화가 32K를 넘으면 Ollama가 어떻게 처리할지는 확인하지 않았습니다.
    • Claude Code에는 CLAUDE_CODE_DISABLE_UNKNOWN_MODEL_WINDOW_ENFORCEMENT라는 설정도 있습니다. 이름으로 보면 알아보지 못한 모델의 길이 제한을 끄는 설정이지만, 동작은 확인하지 않았습니다.
  • 기억할 길이를 늘리면 문턱도 함께 올라가지만, 그만큼 메모리를 더 씁니다. 이번 Mac mini(24GB)에서 Qwen3.8은 32K에서도 이미 메모리를 넘었습니다.
