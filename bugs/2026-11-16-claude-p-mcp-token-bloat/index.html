claude -p로 짧은 질문을 보냈는데 MCP와 스킬 목록까지 실려 토큰이 5.6배가 된다

로컬 모델과 같은 질문을 Claude에게 보내 비교하려다, Claude 쪽만 58,943토큰을 읽고 $0.24가 나왔습니다. 연결해 둔 MCP와 스킬 목록이 함께 실린 탓이었습니다.

상태
해결됨
대상
Claude Code CLI 2.1 (claude -p)
환경
macOS 27.2, Claude Code 2.1.325
올린 날
2026-11-16
읽는 시간
약 2분

증상

커밋 메시지 초안을 로컬 모델과 Claude에게 똑같이 물어 비교하는 스크립트를 만들었습니다. Claude 쪽은 claude -p로 부르고, 공정하게 하려고 시스템 프롬프트를 바꾸고(--system-prompt) 도구를 모두 껐습니다(--tools ""). 그런데 결과의 사용량에 58,943토큰을 읽었고 API 요금으로 $0.2373이 찍혔습니다. 같은 질문이 로컬 모델에서는 7천 토큰 안팎이었습니다.

재현 순서

  1. MCP 서버 여러 개와 스킬 수십 개가 설정된 환경에서, 아래처럼 짧은 질문을 보낸다.
  1. 결과 JSON의 usage와 total_cost_usd를 본다. 읽은 양이 질문 길이보다 훨씬 크다.

원인

확인한 것

  • --system-prompt는 기본 시스템 프롬프트만 바꿉니다. --tools ""는 기본 제공 도구만 끕니다.
  • 그래서 연결해 둔 MCP 서버의 도구 목록과 스킬 목록은 그대로 실립니다. 아래 플래그로 이 둘을 빼자 읽는 양이 바로 줄었습니다.

추정한 것

  • MCP 쪽과 스킬 쪽이 각각 얼마를 차지했는지는 나눠 재지 않았습니다.

해결

플래그 세 개를 더하고, 저장소 밖의 빈 폴더에서 실행했습니다. 프로젝트 폴더의 설정 파일과 문서를 읽어 들이지 않게 하려는 것입니다.

플래그 하는 일
--strict-mcp-config --mcp-config로 준 MCP 서버만 쓴다. 주지 않았으니 MCP를 하나도 싣지 않는다
--disable-slash-commands 스킬과 명령 목록을 싣지 않는다
--setting-sources project 사용자 설정은 읽지 않고 프로젝트 설정만 읽는다. 빈 폴더라 읽을 것이 없다

같은 질문이 58,943토큰에서 10,599토큰으로, 요금은 $0.2373에서 $0.0441로 줄었습니다. 로컬 모델과 남은 차이는 모델마다 글자를 토큰으로 자르는 방식이 다르고, Claude Code가 기본으로 붙이는 내용이 조금 있어서로 봅니다. --bare도 많은 것을 빼 주지만 도움말에 「키체인을 읽지 않는다」고 나와 있습니다. 키체인에 저장된 로그인으로는 쓰기 어려울 것 같아 고르지 않았고, 직접 시험하지는 않았습니다.
